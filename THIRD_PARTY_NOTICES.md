## `khmer-segment` dictionary data (version 0.9.2)

`src/KhmerAutoCorrection.Core/Assets/KhmerDictionary.tsv` is a mechanical UTF-8 TSV export of the frequency dictionary bundled with the [`khmer-segment`](https://www.npmjs.com/package/khmer-segment) package, version 0.9.2.

The package is MIT licensed, copyright (c) 2026 Phalla. Its README identifies the dictionary as a 101,107-word collection sourced from `khmerlbdict` (MIT), the Royal Academy of Cambodia's Khmer Dictionary, and Sovichea's Khmer Segmenter dictionary.

Before distributing a production installer, review the redistribution terms and attribution requirements for every underlying data source, especially the Royal Academy and Sovichea portions. This repository does not make a broader licensing claim for those source data sets.
